⚠️ DISCLAIMER: Grand Theft Auto VI has not released yet. All trophy descriptions are sourced from official PlayStation pre-release trophy listings. All guide text is speculative, written from trophy names only, NOT verified by real gameplay. This is a planning tracker only.

Leonida Trophy Atlas is an offline web guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that names its source beside it, a localStorage checklist with export and import, filters by kind (story, missable, collectibles, activities, feats, online), a spoiler-safe mode that hides story trophies until earned, and a six-stage roadmap to the platinum with missable trophies flagged — all built from the official trophy descriptions, with an honest note that the game is unreleased so the guides are plans to check against the cited guides once it is out.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. It also works by serving `app/` with any static file server, with the network off — it makes no network requests.
